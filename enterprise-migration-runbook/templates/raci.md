# RACI template

Replace roles with named teams and confirm exactly one accountable owner per activity.

| Activity | Business owner | App team | Platform | Security | Operations |
|---|---|---|---|---|---|
| Scope and acceptance criteria | A | R | C | C | C |
| Dependency and data discovery | C | A/R | C | C | C |
| Target platform readiness | C | C | A/R | C | C |
| Security and privacy review | C | C | C | A/R | C |
| Change approval | A | R | R | C | C |
| Cutover execution | C | A/R | R | C | R |
| Rollback decision | A | R | R | C | C |
| Hypercare and handover | C | R | C | C | A/R |

R = Responsible, A = Accountable, C = Consulted. Adjust this template to the organization's governance model.
